# Assumptions
- All tables in the restaurant will have a unique QR code.
- Once you scan that QR code, you will be redirected to the chatbot interface on your browser. 
- There is no need for multiple chats in the sidebar of the interface as one user will only have one chat.
- Demo is restricted to just one restaurant with one giant menu.
- There's no need for user authentication and user authorization.
- for order confirmation, chatbot will ask user necessary details and just place the order itself by json response
- There will be a private kitchen interface will orders will pop up.
